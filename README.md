# 証券外務員Pass プライバシーポリシー

最終更新日: 2026年7月27日

証券外務員Pass（以下「本アプリ」）は、学習機能、広告表示、アプリ内課金の提供のために、端末上の学習履歴および外部サービスが提供する識別子等を利用する場合があります。

本アプリは、ログインやアカウント作成を必要としません。

## 収集する情報

- 学習履歴、回答履歴、正誤履歴、苦手問題、連続学習日数など、アプリ内で保存される学習データ
- アプリの設定情報
- 広告配信や広告効果測定に必要な識別子
- アプリ内課金の購入状態を管理するために必要な情報
- クラッシュ、不具合、利用状況の把握に必要な技術情報

本アプリは、氏名、住所、電話番号、メールアドレス、連絡先、正確な位置情報を、アカウント情報として独自に取得しません。

## 利用目的

- 問題演習、復習、学習進捗表示の提供
- 誤答優先学習、苦手問題、連続学習日数などの学習機能の提供
- 広告表示
- アプリ内課金の購入状態の確認、復元、管理
- 不具合調査、品質改善、クラッシュ解析

## 学習データの保存

学習履歴、回答履歴、苦手問題、連続学習日数などの学習データは、原則として利用者の端末内に保存されます。

本アプリは、学習履歴を管理するための独自アカウントサーバーを運営していません。端末の削除、アプリの削除、端末変更などにより、端末内の学習データが失われる場合があります。

## 広告について

本アプリでは、Google Mobile Ads を利用して、バナー広告、インタースティシャル広告、リワード広告を表示する場合があります。

Google Mobile Ads では、広告配信、広告効果測定、不正防止などのために、端末情報、広告識別子、利用状況に関する情報が利用される場合があります。これらの情報の取り扱いは、Google のポリシーに従って管理されます。

## アプリ内課金について

本アプリでは、非消耗型のアプリ内課金により、全問題の利用、広告非表示、詳細解説、選択肢ごとの解説、苦手問題モードなどの機能を提供する場合があります。

購入処理は、iOSではAppleが提供するApp Store、AndroidではGoogleが提供するGoogle Play Billingの仕組みを通じて行われます。購入状態の管理にはRevenueCatを利用します。RevenueCatでは、購入状態の確認、復元、課金機能の提供に必要な識別子や購入情報が取り扱われる場合があります。

## 利用状況の分析について

本アプリでは、機能の利用状況の把握と品質改善のためにFirebase Analyticsを利用する場合があります。Firebase Analyticsでは、アプリのバージョン、端末やOSに関する情報、アプリ内の操作イベント、広告識別子などが取り扱われる場合があります。

本アプリは、Firebase Analyticsを通じて氏名、住所、電話番号、メールアドレス、正確な位置情報を独自に送信しません。

## 第三者サービス

本アプリでは、広告配信、課金管理、品質改善のために、以下の第三者サービスを利用する場合があります。各サービスで取り扱われる情報は、それぞれのプライバシーポリシーに従って管理されます。

- Google Mobile Ads
- Firebase Analytics
- RevenueCat
- Google が提供する Google Play、Google Play Billing、診断関連サービス
- Apple が提供する App Store、アプリ内課金、クラッシュログ、診断関連サービス

## 外部送信

広告配信、課金管理、クラッシュ解析、品質改善のため、第三者サービスに端末情報、広告識別子、購入情報、クラッシュ情報、診断情報などが送信される場合があります。

本アプリは、利用者が入力した氏名、住所、電話番号、メールアドレス、連絡先、正確な位置情報を独自に収集して外部送信する機能を持ちません。

## データの削除

端末内に保存された学習履歴、回答履歴、ブックマーク、学習統計、設定情報は、アプリ内のデータ初期化機能またはアプリの削除により削除できます。

広告、分析、購入管理など第三者サービスが取り扱う情報の削除や取り扱いに関するご相談は、下記のお問い合わせ先へご連絡ください。内容を確認し、適用される法令および各サービスの手続に従って対応します。
